本文是 Flare Engine 跨 C++、C ABI、C# `F_` SDK、HLSL 着色器与资产文件的统一命名速查表。凡写入项目 JSON、跨语言 ABI 或资产绑定的标识符，调用方和历史工程都会依赖它的精确拼写与大小写，开工前和改名评审时请先对照本页。

## 必须逐字匹配的公开契约

下列标识一旦变更会影响跨语言链接、本地化查找或存量项目读取：

### 1. C ABI 与 C# P/Invoke

- C 导出函数一律 `flare_` + 小写蛇形命名，枚举/结构体一律 `FLARE_` 前缀，全部标记 `FLARE_NOEXCEPT`。
- C# `NativeMethods` 的 `[LibraryImport(Library, EntryPoint = "...")]` 必须与 C 头文件逐字一致：
  - C 声明：[`flare_session_create`](https://github.com/xuu-xuu-xuu/FlareEngine/blob/4030e29/Source/FunctionLayer/Scripting/NativeBridge/EngineNative.h#L122)
  - C# 声明：[`NativeMethods.Create`](https://github.com/xuu-xuu-xuu/FlareEngine/blob/4030e29/Source/FunctionLayer/Scripting/Managed/NativeMethods.cs#L21)

### 2. 脚本 ID 与 `[F_Expose]` 字段

- 编辑器新建脚本模板默认不写 `[F_Script]`（[`EditorScriptTools.cpp#L420-L423`](https://github.com/xuu-xuu-xuu/FlareEngine/blob/4030e29/Source/ToolLayer/Editor/EditorScriptTools.cpp#L420)），[`ScriptRegistry.IdOf(Type)`](https://github.com/xuu-xuu-xuu/FlareEngine/blob/4030e29/Source/FunctionLayer/Scripting/Managed/Behaviour.cs#L217) 直接使用完整类名（无命名空间时即类名）；编辑器内重命名脚本或唯一类名热重载时会自动迁移 `.bindings.json`。
- 跨重构需永久锁死 ID 的内置示例脚本显式标注 `[F_Script("sample.project_mover")]` 等稳定键。
- `[F_Expose]` 字段以 C# **字段原名**作为 `.bindings.json` 中 `Fields` 字典的键。

### 3. 原生反射属性键与本地化文本键

- 反射属性键采用 `域.属性`（如 `body.linearDamping`、`material.clearCoatWeight`），对应 UI 显示标签使用独立稳定文本键（如 `Feature.Body.LinearDamping`、`Property.Material.ClearCoat.Weight`），修改中文文案只改语言表不改属性键。
- 新增面向用户的文本键必须同步写入 `Resources/Localization/zh-CN.txt` 与 `en-US.txt`；组件类型 ID 沿用已注册的稳定数值 [`FeatureComponents.h#L10`](https://github.com/xuu-xuu-xuu/FlareEngine/blob/4030e29/Source/FunctionLayer/Runtime/FeatureComponents.h#L10) · [`FeatureComponents.cpp#L16`](https://github.com/xuu-xuu-xuu/FlareEngine/blob/4030e29/Source/FunctionLayer/Runtime/FeatureComponents.cpp#L16)。

### 4. `AssetId` 与 `FlareEngine.*` 资产格式标识

- **`AssetId`**：固定为 **32 个小写十六进制字符**（128 位随机 ID），资产改名或移动目录时保持 ID 不变（校验见 [`Project.cpp#L90`](https://github.com/xuu-xuu-xuu/FlareEngine/blob/4030e29/Source/ToolLayer/Tools/Project.cpp#L90)）。
- **资产与配置文档格式标识**：全部统一为 `FlareEngine.*` 前缀（旧工程中的 `SelfEngine.*` 在读取端保留向下兼容，新写出统一用 `FlareEngine.*`）：

## 跨模块交接与改名评审清单

::: warning 改名前必查
1. **先追消费者再改名**：修改类名、暴露字段名或 JSON 键前，先全局搜索它的持久化读取方（`.scene.json`、`.bindings.json`、`.material.json`、C# P/Invoke 与测试用例）。
2. **显式脚本 ID 与字段迁移**：如果改了类名但保留相同的 `[F_Script("...")]` 显式 ID，旧 `.bindings.json` 仍能匹配；但如果同时改动了 `[F_Expose]` 字段名，旧绑定里仍存旧键，必须同步提供迁移并用既有模板工程重开验证。
3. **单一真相源**：跨层共享的结构体、错误键和格式常量只在一处定义，生产方、消费方和测试共同引用，不复制第二套声明。
:::
