# 导入 FBX / GLB 模型

本页带你把外部制作好的 3D 模型导入项目，并用最快的方式放到场景里。

::: info 静态模型 vs 带骨骼动作的模型
- **静态模型**（道具、建筑、地形块）：支持 `.fbx`、`.glb`、`.gltf`。
- **骨骼动画角色**（需要播放走路、挥手等动作）：请导出为 **`.glb`**（推荐）或 `.gltf`，详见 [让模型播放骨骼动画](animate-model.md)。Flare 的 FBX 导入器目前仅针对静态网格。
:::

## 1. 导入外部模型文件

1. 在 **资源** 面板顶栏点击 **导入**（或按快捷键 `Ctrl + I`、顶部工具栏 **导入** 按钮）。
2. 在弹出的文件选择框里选中一个 `.fbx`、`.glb` 或 `.gltf` 文件（可以直接选项目文件夹之外的位置），点击 **打开**。
3. 编辑器会自动把模型及其关联贴图复制到项目内容目录并登记为资产。留意底部状态栏，看到 **「资源导入成功」** 就完成了。
4. 在 **资源** 面板里找到刚导入的模型（例如 `crate.fbx` 或 `character.glb`）。选中它后，右侧 **属性** 面板会直接展示子网格数、顶点数、三角面数（以及动画剪辑数）。

::: warning 导入失败或模型缺少贴图？
- 打开左下方的 **控制台** 面板查看具体报错原因。
- 如果 FBX 或 `.gltf` 引用了外部贴图文件，请先确认贴图文件还留在模型记录的相对路径下，再重新导入。更省心的做法是在 Blender / Maya 导出时直接选择「内嵌纹理的 `.glb`」。
:::

## 2. 将模型放入场景（两种方法）

### 方法 A：拖放贴地落场（推荐）
1. 在 **资源** 面板按住模型条目，直接拖进左上方的 **场景视口**。
2. 鼠标在地面或已有物体表面移动时，落点会自动沿视口射线贴合表面（按住 `Ctrl` 还会按网格对齐）。
3. 松开鼠标左键，模型就会精准落在你指的位置！

### 方法 B：一键居中加入场景
1. 在 **资源** 面板点击选中模型。
2. 在右侧 **属性** 面板点击 **将模型加入场景**。
3. 编辑器会在原点创建同名实体，并自动把视口镜头聚焦到新物体上。

::: tip 随时撤销与保存
放完模型不满意，按 **`Ctrl + Z`** 就能一步撤回；满意的话按 **`Ctrl + S`** 保存场景。
如果导入的是带骨骼和动作的 `.glb` / `.gltf`，编辑器在加入场景时还会自动挂好 **动画角色** 组件并选中默认动作，接下来可以直接去 [让模型播放骨骼动画](animate-model.md) 预览动作。
:::
