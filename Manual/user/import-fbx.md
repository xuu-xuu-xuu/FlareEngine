# 导入 FBX

这页适用于静态模型。如果模型要播放走路等骨骼动作，请按[让模型播放骨骼动画](animate-model.md)准备 GLB。

1. 在 **资源** 面板点击 **导入**，选择一个 `.fbx` 文件，再点 **打开**。可以直接选择项目外的文件。
2. 等待底部状态从「正在导入资产」变为「资源导入成功」。在 **资源** 列表里找到模型文件名，例如 `crate.fbx`。
3. 若提示失败，打开 **控制台** 查看原因。模型引用外部贴图时，先确认贴图仍在 FBX 引用的相对路径下，再重新导入。

4. 在 **资源** 面板选中模型，在 **属性** 点 **将模型加入场景**。编辑器创建同名物体并将视口对准它。点 **保存** 保留物体，或按 **Ctrl+Z** 撤销这次创建。

如果导入的是带骨骼和动作的 GLB 或 glTF，编辑器还会绑定动画资产。接下来可以[在视口里选动作并预览](animate-model.md)。
