# 运行预览与实时调参

1. **选择预览模式**：在左下方 **摄像机视口** 顶栏，可选择 **窗口预览**（默认，在摄像机面板内运行游戏，同时保留场景视口和右侧属性栏）或 **全屏预览**（启动运行后画面自动铺满编辑区，沉浸试玩；按 `Esc` 可释放鼠标或退出全屏）。
2. **启动运行**：点击顶部工具栏中央的 **▶ 运行预览**。游戏从场景中的活动摄像机视角开始运行（不会改变你在场景视口里的观察机位）。若勾选了控制台的 **运行清空**，每次开跑会自动清掉旧日志。
3. **运行中实时调参（Play Mode 调参）**：游戏运行期间，你仍可在右侧 **属性** 面板实时拖动脚本的 `[F_Range]` 速度滑块、调整灯光强度/颜色或修改物体位置，画面与脚本逻辑会立即响应，方便快速打磨手感。
4. **暂停与单步**：点击 **⏸ 暂停** 定格模拟，每点一次 **⏭ 单步** 精确推进一个模拟帧，适合排查碰撞或动画瞬间；再点一次暂停恢复运行。
5. **停止并安全还原**：点击 **⏹ 停止预览** 返回编辑状态。运行期间产生的位移以及临时调参会自动还原为运行前的场景状态，避免误改存档；记下满意的数值后在编辑态填入并按 `Ctrl+S` 保存即可。

如果预览无法开始，请查看 **控制台** 的提示（场景中至少需要一个启用的摄像机；「基础 3D 示例」已自带 `Main Camera`）。需要把玩家看到的画面录成视频时，见[连续抓帧并导出 MP4](record-video.md)。
