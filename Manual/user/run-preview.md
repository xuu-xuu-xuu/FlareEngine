# 运行预览与实时调参

写好脚本、摆好灯光之后，你随时可以在编辑器里一键开跑，一边操作游戏一边观察场景变化，甚至把试玩时调顺手的参数直接保留回编辑场景。

## 1. 启动、暂停、单步与全屏预览

1. **选择预览方式**：在左下角 **摄像机视口** 的顶栏，可以切换两种试玩体验：
   - **窗口预览**（默认）：游戏在左下角 **摄像机视口** 运行，同时保留 **场景视口**、**场景层级** 和 **属性** 面板，最适合边跑边调试。
   - **全屏预览**（快捷键 **`F11`**）：开跑后游戏画面自动铺满整个工作区，沉浸体验玩家视角。
2. **启动预览**：点击顶部工具栏中央的 **`▶`（运行预览）**，或直接按 **`F5`** / **`Ctrl + P`**。
   - 如果你刚在外部改过 C# 代码还没手动编译，编辑器会**自动先完成编译再启动**；如果有语法报错，会拦截启动并把错误信息标红显示在 **控制台**。
   - 若勾选了控制台顶栏的 **运行清空**，每次开跑都会自动清掉旧日志，排查问题更清爽。
3. **暂停与逐帧单步**：
   - 按 **`F6`**（或点工具栏 **`Ⅱ`**）暂停模拟。
   - 暂停状态下，每按一次 **`F7`**（或点 **`▸│`**）精确推进一帧，排查瞬间碰撞、子弹轨迹或动画过渡非常好用。
   - 再次按 `F6` 恢复运行。
4. **停止预览**：点击顶部工具栏的 **`■`（停止预览）**，或按 **`F5`** / **`Ctrl + P`** / **`F8`** 返回编辑态。

| 快捷键 | 按钮 | 作用 |
| :--- | :--- | :--- |
| `F5` 或 `Ctrl + P` | `▶` / `■` | 开始或停止运行预览 |
| `F6` | `Ⅱ` | 暂停 / 继续游戏模拟 |
| `F7` | `▸│` | 暂停状态下逐帧单步推进 |
| `F8` | — | 直接停止运行预览 |
| `F11` | 窗口预览 / 全屏预览 | 切换窗口预览与全屏预览 |

## 2. 第一人称锁定鼠标时如何安全退出预览？

很多第一人称脚本会在 `F_Start()` 里写 `F_Cursor.Locked = true;` 把鼠标锁在游戏画面中央。在编辑器里试玩这类游戏时，退出只需两下：

1. 按一下键盘左上角的 **`Esc`** 键：引擎会**立即释放并重新显示鼠标光标**（不会强制关闭游戏）。
2. 把鼠标移到编辑器顶部工具栏，直接点击 **`■`（停止预览）**（或者直接按 `F5` / `F8`）即可安全回到编辑态。

::: tip 想接着试玩？
按 `Esc` 释放鼠标调整完面板参数后，只需在 **摄像机视口** 画面里再左键点一下，光标就会重新锁回游戏视角。
:::

## 3. 运行态场景层级：实时观察动态 `Instantiate` 生成的实体

进入运行预览后，右侧的 **场景层级** 面板会自动切换显示当前**运行世界（Play World）**的实时实体树：

- 脚本在运行中调用 `Instantiate(...)` 生成的子弹、敌人、特效节点，都会**实时出现在场景层级中**；调用 `Destroy(...)` 销毁后也会立即消失。
- 你可以直接在运行态的 **场景层级** 点击选中任意动态实体或原有实体，查看它此刻的实时坐标、旋转、速度和脚本字段值，排查“为什么生成的物体飞歪了 / 没显示”一目了然。

## 4. 边玩边调参，并勾选 [保留修改] 写回编辑态

默认情况下，为了防止你试玩把场景弄乱，**停止预览后所有位移与临时改动都会自动还原**。但当你一边试玩一边调出了最舒服的手感（比如灯光强度、相机角度、角色跳跃速度或脚本 `[F_Range]` 滑块值），不必拿纸记数字再重填：

1. 在运行预览期间，选中你想调整的实体，直接在右侧 **属性** 面板里拖动滑块、改位置、改灯光或改脚本参数——游戏画面会立刻响应。
2. 调到满意后，点击 **属性** 面板顶部运行态横幅右侧的 **[保留修改]** 按钮，按钮会变为 **`✓ 停止预览后将把此实体修改写回场景`**。
   - 可以同时给多个不同实体都点上 **[保留修改]**。
3. 点击 **停止预览 (`■`)** 返回编辑态：刚才标记的那些实体的组件参数与脚本暴露字段会**自动写回编辑场景**（未标记的实体仍然安全还原）。
4. 写回操作会自动打包成一条标准的编辑历史，如果后悔了按一次 **`Ctrl + Z`** 就能撤销；满意的话按 **`Ctrl + S`** 正式保存场景。

::: warning 启动预览提示「运行预览需要至少一个启用的相机」？
请检查 **场景层级** 中是否存在带有 **相机** 组件且处于启用状态的实体（且其 **主相机** 开关已开启）。你也可以点击 **相机** 组件内联告警条上的 **[设为唯一主相机]** 一键修复。
:::
