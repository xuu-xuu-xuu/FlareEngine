# 给玩家提供画质设置

导出 Windows 游戏后，玩家可以双击包内的 `Play.exe` 进入游戏。第一次运行使用「跟随项目」，也就是你在各个场景里调好的画面。

## 玩家怎么选

1. 点击游戏画面右上角的「画质 · F10」，或按 **F10**。游戏暂停，角色不会跟着菜单按键移动。
2. 点击一个档位，或按 **↑ / ↓** 选择。「跟随项目」恢复作者为当前场景设置的画质；另外三个档位由作者配置。
3. 点「应用并保存」或按 **Enter**，回到游戏看效果。按 **Esc** 或点「取消」则保留原来的画质。同一 Windows 用户下次打开这个游戏，会沿用上次保存的选择。

在 Flare 抚草的镜头里，可以观察手前方细草的边缘：引擎预设的「高画质」使用 4× 空间采样，需要更多 GPU 算力；「均衡」使用较轻的 FXAA；「性能优先」还会关闭阴影和泛光。实际效果取决于游戏作者配置的档位。若场景明确关闭后处理，或正在使用不支持这组设置的实例化渲染路径，菜单只允许「跟随项目」。

## 制作者怎么配

打开编辑器的「项目设置」，找到「在游戏里显示画质菜单」。保持勾选，分别为「性能优先」「均衡」「高画质」选择抗锯齿方式，以及是否保留场景阴影、泛光。勾选「保留」不会给原本没有阴影或泛光的场景强行加上效果。保存项目设置，重新导出游戏后生效。

「玩家偏好标识」用来区分不同游戏，留空则使用项目名。若游戏会改名，发行前可填写一个以后不变的标识；这样更新游戏后，玩家仍能沿用原来的选择。

玩家选档不会改写场景文件。[连续抓帧与视频导出](record-video.md)使用场景画质，也不会录入画质按钮或菜单。
