# 给玩家提供画质设置

把游戏导出发给不同配置电脑的玩家后，低配机想关阴影保流畅，高配机想开 4× 抗锯齿看清细草边缘。Flare 已内置开箱即用的玩家画质菜单（`F10`），**零代码**就能配好三档画质并自动记住玩家选择。

## 1. 先了解默认画质行为

- 玩家双击导出包里的 `Play.exe` 首次进入游戏时，默认使用 **「跟随项目」**——也就是你在编辑器每个场景的 **场景渲染设置** 里调好的原始画面。
- 如果你的某个 3D 场景没有单独挂载 **场景渲染设置**，编辑器、运行预览和导出游戏会自动共用一套高质量默认渲染配置（完整 PBR + IBL 多散射 + 法线高光防闪烁 + 三级方向光软阴影 + ACES 色调映射 + 4× 空间抗锯齿）。

## 2. 制作者怎么配置画质档位（4 步搞定）

1. 在编辑器顶部菜单点击 **项目 → 项目设置**（或按快捷键 **`Ctrl + ,`**）。
2. 找到 **在游戏里显示画质菜单**，保持勾选。
3. 依次为下面三个玩家可选档位配置参数：
   - **性能优先**（默认思路：关闭阴影和泛光，优先保证帧率流畅）
   - **均衡**（默认思路：保留场景阴影，使用轻量 FXAA 抗锯齿）
   - **高画质**（默认思路：使用 4× 空间采样 + FXAA，细草和斜边更稳，GPU 开销更高）

   每一档都可以自由设定三个开关：

   | 配置项 | 可选值与说明 |
   | :--- | :--- |
   | **抗锯齿** | `沿用场景` / `关闭` / `轻量抗锯齿（FXAA）` / `时间抗锯齿（TAA）` / `4× 空间采样 + FXAA` |
   | **保留场景阴影** | 取消勾选会关闭该档位阴影以提速；勾选只表示“保留原本就开的阴影”，**不会**给原本关掉阴影的场景强行加阴影。 |
   | **保留场景泛光** | 同上，控制是否保留场景已启用的辉光（Bloom）。 |

4. （可选）填写 **玩家偏好标识**：用来在玩家系统目录里区分不同游戏的存档位置，留空时默认使用项目名。如果发行前可能会改项目名，建议填一个固定不变的英文 ID（例如 `my-studio-forest-demo`），以后发更新包时玩家已保存的画质选择不会丢。
5. 点击面板底部的 **保存**，然后重新执行 **构建与导出**，新配置就会打进独立游戏包里。

## 3. 玩家在游戏里怎么切换画质

在运行导出的 `Play.exe` 时：

1. 点击画面右上角的 **「画质 · F10」** 按钮，或直接按键盘 **`F10`**。打开菜单时游戏会自动暂停，角色不会乱动。
2. 用鼠标点击，或按 **`↑` / `↓`** 方向键在 **跟随项目 / 性能优先 / 均衡 / 高画质** 之间挑选档位。
3. 点击 **应用并保存**（或按 **`Enter`**），画面立即切换生效并永久记录到当前 Windows 用户的本地配置目录；按 **`Esc`** 或点 **取消** 则保留原画质。

::: info C# 脚本也能读写当前画质档位吗？
可以。如果有自制设置页面，可在脚本里通过 `EngineSession.PlayerQuality`（枚举 `F_QualityLevel.Project / Performance / Balanced / High`）查询或切换档位。
:::

::: warning 什么情况下菜单里只能选「跟随项目」？
如果当前场景在 **场景渲染设置** 里显式关闭了 **启用后处理**，或者启用了实验性的 **前向实例化** 路径，运行时会提示「当前场景未启用兼容的后处理」，此时画质菜单仅允许选择「跟随项目」。此外，[连续抓帧并导出 MP4](record-video.md) 始终按作者设定的场景原画质录制，不会把右上角「画质 · F10」按钮录进成片里。
:::
