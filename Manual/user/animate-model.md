# 让模型播放骨骼动画

准备一个带骨架、蒙皮和已命名动画片段的 `.glb` 模型。下面以走路片段 `Walk` 为例：配置完成后，导出的游戏里应能看到角色反复迈步，无需编写脚本。

## 导入模型

1. 打开带有相机的项目。在 **资源 → 导入** 选择模型。推荐把网格、骨架和动画一起导出成单个 GLB；使用 `.gltf` 时需要同时保留它引用的文件。Flare 的 FBX 导入器只支持静态模型。
2. 等待「资源导入成功」。展开资源面板，确认能看到刚导入的文件。下一步在属性面板直接按文件名选择，无需复制资源 ID。

## 将角色放入场景并预览

在 **资源** 中选中 GLB，在 **属性** 点 **将模型加入场景**。视口会对准新角色，编辑器会给它配置网格和动画资产。有 `Idle` 时默认选它，否则选第一个动作。单击 **动画片段名** 选择动作，例如 Flare 的 `BendTouch`。

点 **预览所选动作** 可在场景视口中单独播放这个角色，再点 **暂停动作预览** 可停在当前姿势。在 **预览位置（秒）** 输入时间并按 Enter 即可检查具体姿势。切换对象或片段会结束这次预览。点顶部的 **运行预览** 可查看整个场景和项目脚本。

## 给已有物体换模型或动作

在 **场景层级** 右键选择 **创建空物体**，选中它，放在主相机能拍到的位置。在右侧 **属性 → 添加组件** 先加 **网格**，再加 **动画角色**。点击属性的值即可编辑，文本输入后按 Enter 确认。

| 属性 | 填什么 |
| --- | --- |
| 网格 → 网格资源 | 点开列表，按项目内路径选择刚导入的模型。 |
| 动画角色 → 动画资产 | 从列表选择**同一个模型**，让姿态对应到这个网格。 |
| 动画角色 → 动画片段名 | 点开列表，选择模型里实际存在的动作，例如 `Walk`。菜单保留原始片段名；如果提示没有动作，检查导出 GLB 时是否包含动画。 |
| 动画角色 → 播放速度 | 先填 `1`（原速）。`0.5` 是半速，`0` 停在当前姿态。 |
| 动画角色 → 正在播放、循环播放 | 都打开。只想播一次时关闭 **循环播放**，动作会停在末尾。 |

## 在游戏里看结果

点击 **保存**。按[导出游戏](record-video.md#export-game)那一步生成游戏包，在同一个 PowerShell 窗口执行下面一行，打开玩家窗口：

```powershell
& $launcher
```

也可以直接双击游戏包里的 `Play.exe`。看角色的手脚是否反复做出预期动作，然后关闭窗口。如果只有静止网格，先核对两个模型和所选片段，再检查物体、组件和 **正在播放** 均已启用，速度大于零。如果连网格也看不到，先检查相机朝向和物体位置。每次更改场景后都要保存并重新导出，旧游戏包保留的是旧场景。

想把动作保存成视频，继续看[连续抓帧并导出 MP4](record-video.md#capture)。要在游戏中按事件切换动作，见开发者手册的 [PlayAnimation](../runtime/skeletal-animation.md#playanimation)。
