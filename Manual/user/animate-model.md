# 让模型播放骨骼动画

准备一个带骨架、蒙皮和已命名动画片段的 `.glb` 模型。下面以走路片段 `Walk` 为例：配置完成后，导出的游戏里应能看到角色反复迈步，无需编写脚本。

## 导入模型，找到资源 ID

1. 打开带有相机的项目。在 **资源 → 导入** 选择模型。推荐把网格、骨架和动画一起导出成单个 GLB；使用 `.gltf` 时需要同时保留它引用的文件。Flare 的 FBX 导入器只支持静态模型。
2. 等待「资源导入成功」。选中模型，在 **属性 → 源文件路径** 找到它在项目里的位置。用文本编辑器打开旁边的 `模型名.glb.asset.json`，复制 `id` 的值，不含引号。
3. 确认片段名，包括大小写。可查看制作模型时的动作名称，也可在项目的 `.cache/assets/<资源 ID>.model.json` 中查看 `model.animations` 各项的 `name`。如果列表为空，应重新导出包含动画的模型。

## 在同一个物体上配置网格和动画

在 **场景层级** 右键选择 **创建空物体**，选中它，放在主相机能拍到的位置。在右侧 **属性 → 添加组件** 先加 **网格**，再加 **动画角色**。点击属性的值即可编辑，文本输入后按 Enter 确认。

| 属性 | 填什么 |
| --- | --- |
| 网格 → 网格资源 | 粘贴模型的资源 ID，使物体显示这个模型。 |
| 动画角色 → 动画资产 | 粘贴**同一个 ID**，让姿态对应到这个网格。 |
| 动画角色 → 动画片段名 | 填模型中实际存在的片段名，如 `Walk`。默认值 `Idle` 只适用于有同名片段的模型。 |
| 动画角色 → 播放速度 | 先填 `1`（原速）。`0.5` 是半速，`0` 停在当前姿态。 |
| 动画角色 → 正在播放、循环播放 | 都打开。只想播一次时关闭 **循环播放**，动作会停在末尾。 |

## 在游戏里看结果

点击 **保存**。按[导出游戏](record-video.md#export-game)那一步生成游戏包，在同一个 PowerShell 窗口执行下面一行，打开玩家窗口：

```powershell
& $launcher
```

看角色的手脚是否反复做出预期动作，然后关闭窗口。如果只有静止网格，先核对两个 ID 和片段名，再检查物体、组件和 **正在播放** 均已启用，速度大于零。如果连网格也看不到，先检查相机朝向和物体位置。每次更改场景后都要保存并重新导出，旧游戏包保留的是旧场景。

想把动作保存成视频，继续看[连续抓帧并导出 MP4](record-video.md#capture)。要在游戏中按事件切换动作，见开发者手册的 [PlayAnimation](../runtime/skeletal-animation.md#playanimation)。
