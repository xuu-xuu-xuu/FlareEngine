# 新建项目

1. 打开 **Flare 引擎**启动器，点击 **新建项目**。
2. 将 **模板** 设为 **基础 3D 示例**，在 **项目名称** 输入 `MyFirstGame`。默认父目录是编辑器所在盘根目录下的 `Flare_Project`，也可以点 **浏览…** 另选可写目录。
3. 核对 **最终目录** 并点击 **创建**。例如引擎在 D 盘，默认项目路径就是 `D:\Flare_Project\MyFirstGame`。父目录不存在时会自动建立。

要直接体验内置示例，在启动页点 **打开示例**，选择 **基础 3D 示例**、**渲染工作室** 或 **室内展厅**。启动器会在 `Flare_Project` 中创建可编辑副本并直接打开；下次要继续编辑，从启动器 **最近项目** 双击它即可。

已有项目可以从原位置打开。如果编辑器报告“无法写入项目编辑锁”，并且是从受限目录直接运行的便携包，请把**整包**复制或解压到普通可写目录后再运行其中的 `FlareEditor.exe`。

进入「基础 3D 示例」后，中部 **场景层级** 面板包含一个干净的初始场景：`Main Camera`（主摄像机）、`Directional Light`（方向光）、`Plane`（灰色地面）和 `Cube`（灰色立方体）。

- 做材质与摄影棚布光时，可在新建时选择 **渲染工作室**，内含主相机、方向光、矩形补光和六种示例材质，操作见[用渲染工作室调光](rendering-studio.md)。
- 要体验投影点光、聚光灯、屏幕空间反弹光、倒影与体积雾，可选择 **室内展厅**，操作见[给室内展厅布光](indoor-lighting.md)。
