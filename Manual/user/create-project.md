# 新建项目

1. 打开 **Flare 引擎**启动器，点击 **新建项目**。
2. 将 **模板** 设为 **基础 3D 示例**，在 **项目名称** 输入 `MyFirstGame`。默认父目录是编辑器所在盘根目录下的 `Flare_Project`，也可以点 **浏览…** 另选可写目录。
3. 核对 **最终目录** 并点击 **创建**。例如引擎在 E 盘，默认项目路径就是 `E:\Flare_Project\MyFirstGame`。父目录不存在时会自动建立。

要直接体验示例，在启动页点 **打开示例**，选择 **基础 3D 示例**、**渲染工作室** 或 **室内展厅**。启动器会在 `Flare_Project` 中创建可编辑副本并打开。下次要继续编辑这个副本，从 **最近项目** 打开它。

已有项目可以从原位置打开。如果编辑器报告“无法写入项目编辑锁”，并且是从受限工作区直接运行的便携包，请把**整包**复制或解压到普通应用目录，再运行其中的 `FlareEditor.exe`。无需删除锁文件或以管理员身份运行。

进入编辑器后，左侧 **场景层级** 中应能找到 `Main Camera`、`Directional Light`、`Ground` 和 `Cube`。下次启动 Flare 时，双击最近项目中的 `MyFirstGame` 即可继续。

做材质与布光时，可以在第 2 步选择 **渲染工作室**。模板已带摄影棚环境、主相机、方向光、矩形补光和六种示例材质。操作见[用渲染工作室调光](rendering-studio.md)。

要编辑室内灯具并查看桌脚投影、地坪倒影和光束，选择 **室内展厅**。创建后点 **运行预览** 即可从展厅主相机观察。[给室内展厅布光](indoor-lighting.md)
