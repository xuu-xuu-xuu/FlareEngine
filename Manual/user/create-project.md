# 新建项目

本页带你用 3 步创建第一个可编辑的 Flare 3D 项目，并认识四个内置模板各自适合做什么。

## 三步创建第一个项目

1. 双击打开 **FlareEditor.exe**，在 **Flare 引擎** 启动器中点击 **新建项目**。
2. 填写基础信息：
   - **模板**：选择 **基础 3D 示例**。
   - **项目名称**：输入 `MyFirstGame`（不要包含 `\`、`/`、`:`、`*`、`?` 等特殊路径字符）。
   - **父目录**：默认指向编辑器所在盘根目录下的 `Flare_Project`（例如引擎在 D 盘，默认就是 `D:\Flare_Project`），也可以点击 **浏览…** 选一个你常用的可写文件夹。
3. 核对下方显示的 **最终目录**（例如 `D:\Flare_Project\MyFirstGame`），确认提示为绿色就绪后点击 **创建**。如果父目录还不存在，编辑器会自动帮你建好。

创建完成后会自动进入编辑器主界面。在 **场景层级** 面板里，你会看到一个干净的标准 3D 起步场景：

| 初始实体 | 作用 |
| :--- | :--- |
| `Main Camera` | 默认主摄像机，决定玩家进入游戏时看到的画面。 |
| `Directional Light` | 带实时阴影的方向光（太阳光）。 |
| `Plane` | 灰色地面，用来承接物体和阴影。 |
| `Cube` | 居中摆放的灰色立方体，最适合拿来练手挂脚本和调材质。 |

## 选择合适的项目模板

新建项目或点击启动器上的 **打开示例** 时，可以按目标挑选内置模板：

| 模板名称 | 里面有什么 | 适合场景 |
| :--- | :--- | :--- |
| **空白场景** | 仅预置主相机、方向光与基础地面，极简无多余资源。 | 从零开始搭建自己的正式项目。 |
| **基础 3D 示例** | 主相机、方向光、平面与立方体。 | 新手练手写脚本、试物理、导模型。 |
| **渲染工作室** | 摄影棚主光、冷色矩形补光、6 种 PBR 材质球与柔和环境。 | 调 PBR 材质参数、观察清漆/绒布/拉丝金属与软阴影，见 [用渲染工作室调光](rendering-studio.md)。 |
| **室内展厅** | 展厅建筑、投影点光与聚光灯、雕塑与蓝釉瓶。 | 体验室内局部灯柔和阴影、动态间接光、屏幕空间倒影与体积雾，见 [给室内展厅布光](indoor-lighting.md)。 |

::: tip 用「打开示例」体验内置关卡
如果你只想快速看看渲染效果，在启动器点击 **打开示例** 并选中任意示例即可。启动器会自动在 `Flare_Project` 下复制一份**可自由修改的副本**并直接打开，不会污染原始模板；下次继续编辑时，在启动器左侧 **最近项目** 里双击它就能进。
:::

## 打开已有项目与目录权限提醒

- 点击启动器上的 **打开项目…**，选中任意已有工程目录下的 `project.json` 即可打开。
- 在 **最近项目** 列表中，支持按名称或路径顶部搜索；右键某条记录可 **打开所在目录**、**重新定位…**（项目文件夹挪过位置时很有用）或 **移除记录**。

::: warning 提示「无法写入项目编辑锁」或「编辑器包内的项目为只读」怎么办？
如果你把 Flare 便携包直接解压到了 `Program Files` 等受系统权限限制的目录，或者试图直接打开包内自带的模板文件夹，编辑器会拦截写入以防丢档。请把**整个软件包**移到普通可写目录（如 `D:\Tools\Flare`）再启动，并把项目建在软件包外部的文件夹里。
:::
