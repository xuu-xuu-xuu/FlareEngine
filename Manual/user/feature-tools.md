# 物理、渲染和资源工具

本页介绍编辑器里四类进阶创作工具的具体操作：**物理刚体与胶囊控制器、场景渲染与环境贴图、离线资源烘焙工具、游戏 UI 画布与昼夜时间轴**。

## 1. 物理组件：刚体、球体碰撞与胶囊角色

### 快速搭建物理场景
1. 在 **场景层级** 空白处右键，可直接一键创建：
   - **刚体与盒形碰撞**（默认带立方体网格与物理盒体）
   - **物理球体**（默认带球体网格与球形碰撞）
   - **触发盒区域**（只检测进出，不挡路）
   - **胶囊角色控制器**（专用于玩家和 NPC 行走跳跃）
   - 已有物体也可以在属性面板点 **+ 添加组件** 单独补加。
2. **区分静态地面与动态物体**：
   - 将刚体的 **质量（0 为静态）** 设为 `0`，它就是不会掉落移动的静态墙体/地面；
   - 质量大于 `0` 时受重力下落并响应碰撞冲量。
3. **调碰撞体尺寸**：在 3D 视口选中物体，直接拖动绿色的碰撞线框控制柄就能实时调整半尺寸、球体半径或胶囊高度。

::: warning 物理组件的两条硬约束
- 同一个实体**只能**挂载 **刚体** 或 **胶囊角色控制器** 中的一个（编辑器会自动拦截互斥挂载）。
- 球体/胶囊碰撞所在实体应保持等比缩放且缩放不能为零；若出现非均匀缩放，直接点组件内联告警条上的 **[归一等比缩放]** 即可自动修复。
:::

### 在 C# 脚本中控制刚体与角色
```csharp
using System.Numerics;
using FlareEngine;

public class PhysicsSample : F_Behaviour
{
    public override void F_FixedUpdate(float fixedDelta)
    {
        // 控制动态刚体
        if (TryGetComponent<F_Rigidbody>(out var body) && F_Input.KeyDown(F_Key.Space))
        {
            body.AddImpulse(new Vector3(0f, 6f, 0f));
        }

        // 控制胶囊角色控制器
        if (TryGetComponent<F_CharacterController>(out var controller))
        {
            var input = F_Input.MoveVector;
            var dir = new Vector3(input.X, 0f, -input.Y);
            controller.Move(dir, F_Input.KeyDown(F_Key.Space), fixedDelta);
        }
    }
}
```

## 2. 场景渲染设置与环境贴图光照

1. 在 **场景层级** 右键创建 **场景渲染设置**，展开右侧各个折叠分组即可统一配置全场景画面：
   - **阴影与级联过滤**：方向光 PSSM 三级阴影、PCSS 接触渐软阴影、光源角半径、阴影分辨率。
   - **环境光遮蔽与间接光**：GTAO 环境遮蔽、方向光接触阴影、动态间接光、动态反射、球谐漫反射。
   - **后处理与色调映射**：曝光、自动曝光、ACES 色调映射、辉光（Bloom）、FXAA / TAA / 4× 空间抗锯齿、暗部/中间调/亮部调色与颜色分级（`.selut`）。
   - **体积雾效** 与 **硬件光线追踪 (DXR)**。
2. 如需自定义天空盒环境反射与照明：右键创建 **环境贴图光照**，在 **环境资源 ID** 槽位选用由资源工具烘焙出的 `.seenv` 文件，再调节 **环境强度** 与 **环境旋转（度）**。
3. 按 **`Ctrl + S`** 保存后，配置会同步作用于编辑视口、运行预览和导出的 `Play.exe`。

::: info 场景里有多个「场景渲染设置」谁生效？
同一种场景级配置（如 **场景渲染设置**、**环境贴图光照**）如果启用了多个实例，引擎会确定性地使用 **稳定 ID 最小** 的那个启用实例。另外，勾选实验性的 **前向实例化** 会锁定当前不兼容的阴影与后处理选项，常规项目保持关闭即可。
:::

## 3. 资源与参考工具（离线烘焙与着色器编译）

点击顶部菜单 **面板 → 资源与参考工具**（或在 **资源** 面板右键打开）即可使用所有离线资产加工工具：

1. 在顶部选好 **类别** 和 **操作**。
2. 在 **资源** 面板点击源资产，**源资产 ID 或路径** 会自动同步填入（也可手动填写）。
3. 填好参数后点击 **运行**（后台线程执行，不卡编辑器，运行中随时可点 **取消**）。
4. 生成的派生文件统一存放在项目内容目录的 `Derived/` 子目录下并自动登记到资产清单，**不会覆盖或破坏你的原始源文件**；完成后点 **打开结果** 即可查看。

| 类别 | 包含的操作 | 实用提示 |
| :--- | :--- | :--- |
| **几何烘焙** | **LOD 链**、**当前场景 HLOD**、**Meshlet 簇**、**多视角代理图集（Impostor）**、**顶点压缩分析**、**当前场景导航网格（`.senav`）** | LOD 需要模型具备一定面数才能生成递减层级；HLOD 烘焙前需为参与物体分配独立材质资产；顶点压缩分析只输出内存/误差报告，不改动现有几何。 |
| **图像与着色器** | **HDR 环境烘焙（`.seenv`）**、**BC1 / BC4 / BC5 压缩纹理**、**自定义 PBR 着色器编译（`.sebin`）** | 环境烘焙接收 `.hdr` 图片并生成预过滤立方体贴图；自定义着色器编译会同时生成 PBR、前向、阴影和环境四个通道产物，使用时把主 `.sebin` 赋给材质且确保同目录保留其余通道文件。 |
| **CPU 参考预览** | **大气散射**、**高度雾**、**盒投影与反射预过滤**、**屏幕空间反射**、**AO 与接触阴影** | 使用示例数据在 CPU 侧算出的参考预览，便于学习算法参数，**不会**修改你当前场景的 GPU 渲染开关（真实场景开关请在 **场景渲染设置** 中勾选）。 |

## 4. UI 设计画布与脚本联动（`F_GameUi`）

### 可视化搭建游戏界面
1. 在左上方切到 **UI 设计** 页签（或在 **面板 → UI 设计** 打开），勾选 **运行时画布预览** 查看真实控件。
2. 点击画布空白处，在右侧 **属性** 面板点击创建控件（支持面板、文字标签、图片、按钮、复选框、滑块、进度条、滚动区域、输入框）。
3. 直接拖动绝对定位控件调整位置，拖动右下角手柄改尺寸（绿色标记为锚点，紫色为枢轴，按 `Esc` 取消拖动，`Ctrl + Z / Y` 撤销重做）。
4. 选中按钮等交互控件，在属性面板的 **事件绑定** 里填写 **目标实体 ID**、**脚本 ID** 与 **动作 ID**，点 **保存 UI 文档** 即可。

### 用 C# 脚本动态创建或更新界面
```csharp
using System.Numerics;
using FlareEngine;

public class HudScore : F_Behaviour
{
    private F_UiElement? _label;
    private int _score;

    public override void F_Start()
    {
        // 通过 F_Behaviour 内置的 Ui (F_GameUi) 服务动态创建界面控件
        _label = Ui.Create(UiKind.Label);
        var style = UiStyle.Default;
        style.Offset = new Vector2(24f, 24f);
        style.Size = new Vector2(260f, 36f);
        _label.SetStyle(style);
        _label.SetText("得分：0");
    }

    public override void F_Update(float delta)
    {
        if (F_Input.KeyDown(F_Key.E) && _label is not null)
        {
            _score += 10;
            _label.SetText($"得分：{_score}");
            _label.FadeTo(1.0f, 0.25);
        }
    }
}
```

## 5. 昼夜配置与曲线时间轴（`.tod`）

1. 在 **资源** 面板右键选择 **创建昼夜配置**，生成 `.tod` 资产。
2. 在场景未选中物体（查看 **场景环境**）时，把该 `.tod` 资产拖进 **昼夜配置** 槽位（或点 **`⊙`** 选取），并确认 **场景渲染设置** 中已勾选 **昼夜光照联动**。
3. 在 **资源** 面板点击选中该 `.tod` 文件，即可在右侧属性面板编辑 **一天的模拟秒数**、**日出/日落时刻**、**太阳方位与最大仰角**，以及各个时刻的太阳颜色/强度、天空颜色与雾密度关键帧。
4. 拖动 **预览时刻（0–1）** 可在 3D 视口实时预览从日出、正午、黄昏到午夜的完整光影过渡（独立预览不会改变运行时钟，支持 `Ctrl + Z / Y` 撤销重做，满意后点击 **保存昼夜配置资源** 才写盘）。
