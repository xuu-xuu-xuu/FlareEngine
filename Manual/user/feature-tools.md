# 物理、渲染和资源工具

## 物理组件

1. 在场景层级空白处右键，创建 **刚体与盒形碰撞** 或 **胶囊角色控制器**。已有对象也可在属性面板中添加对应组件。
2. 刚体的 **质量** 为 `0` 时作为静态碰撞体；大于 `0` 时参与模拟。盒形半尺寸乘以对象缩放，调整后可在场景中查看碰撞线框。
3. 点击运行预览。停止后返回编辑时的姿态，运行中的运动不会写回场景文件。

同一个对象只能由刚体或角色控制器中的一个管理。物理变换需要可分解的世界矩阵，缩放不能为零。

C# 获取组件创建的物理对象：

```csharp
var body = entity.Session.Physics.GetBody(entity);
var controller = CharacterController.FromComponent(entity);
```

具体脚本上下文中的会话变量请沿用项目已有写法。

## 场景渲染

1. 在场景层级右键创建 **场景渲染设置**。
2. 在属性面板中设置完整 PBR、曝光、阴影、Bloom、FXAA/TAA、自动曝光和调色。
3. 需要环境光照时创建 **环境贴图光照**，指定资源工具生成的 `.seenv` 资产。
4. 保存场景。配置同时作用于编辑视口、运行预览和导出的游戏。

同一种场景配置有多个启用实例时，使用稳定 ID 最小的实例。实例化与遮挡路径属于实验功能；启用后属性面板会锁定当前不兼容的后处理等选项。HLOD 也是实验功能，物体或材质发生变化时会重新生成单元代理。

## 资源与参考工具

1. 从 **面板** 菜单或资源面板右键打开 **资源与参考工具**。
2. 选择类别和操作，再填写源资产 ID 或项目内路径。选中资源会自动更新这里的来源。
3. 点击 **运行**，完成后查看预览和结果目录。运行中可请求取消。

几何工具提供 LOD、HLOD、Meshlet 和 Impostor 烘焙，以及已有顶点压缩算法的内存和误差分析；图像工具提供环境贴图、BC1/BC4/BC5 和用户 PBR 着色器编译。结果写入项目内容目录的 `Derived` 子目录，保留原文件，成功生成的资产加入项目清单。顶点分析报告不会改变场景的 GPU 顶点布局。

着色器编译会生成 PBR、前向、阴影和环境四个通道的包。把主 `shader.sebin` 资产指定给材质，其他通道文件与它放在同一目录。源码需要符合对应通道的固定接口；只持有旧独立 PBR 包时，编辑器前向通道会显示诊断并使用默认材质着色，需从源码重新编译。

LOD 要求模型具有足够的可简化几何；简单方块可能无法生成多个严格递减的层级。HLOD 文件烘焙需要先分配独立材质资产。环境贴图使用 HDR 输入，尺寸向上取到支持的二次幂。

资源与参考工具中的大气、雾、反射和遮蔽演示使用示例输入计算 CPU 参考结果。要在自己的场景中启用 GPU 环境遮蔽，选中 **场景渲染设置**，勾选 **间接光环境遮蔽（GTAO）**。同一面板中的 **方向光接触阴影** 控制物体接触处的方向光可见度。[用渲染工作室调光](rendering-studio.md)

## UI 和昼夜配置

打开 **UI 设计** 面板，点击画布空白处，再从属性面板创建控件。选中控件后可编辑布局、文字、图像、颜色、值域和事件绑定；Ctrl+Z/Ctrl+Y 撤销重做，保存写入项目已有的 UI 文档。事件绑定 JSON 中填写稳定实体 ID、脚本和方法名。

在资源面板右键创建 **昼夜配置**，将其资产 ID 填入场景环境的昼夜配置字段，再点击 **打开预览**。属性面板可调整时长、太阳轨迹及曲线关键帧，预览暂停和时间不改变运行时钟。曲线编辑支持撤销重做，保存后才修改资源文件。
