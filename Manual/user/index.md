# Flare 使用者文档

欢迎使用 **Flare 引擎**！无论你是第一次做 3D 游戏，还是从其他引擎转过来，这份手册都能带你**纯点选、零命令行**完成建场景、导模型、写 C# 脚本、调光影到打包出独立 Windows 游戏 `Play.exe` 的完整流程。

::: tip 刚拿到源码仓库？
如果你还没有现成的 `FlareEditor.exe` 软件包，请先花几分钟看 [从源码启动编辑器](build-from-source.md) 编译并打开启动器。
:::

## 五步做出你的第一个可玩场景

按下面 5 步走一遍，大约 15 分钟就能跑起一个能键盘移动、带实时光照和热重载脚本的 3D 场景：

```text
  ① 新建项目  ──▶  ② 熟悉 2×3 界面  ──▶  ③ 导入 3D 模型  ──▶  ④ 写 C# 脚本  ──▶  ⑤ 运行与实调
  选基础 3D 示例    视口漫游/拖拽/属性     FBX / GLB 拖落场     零重启热重载       实时改参数并保留
```

1. [**新建项目**](create-project.md) —— 用清爽的「基础 3D 示例」建好你的第一个工程目录。
2. [**编辑器界面与高效交互**](editor-interface.md) —— 搞懂 2×3 分屏布局、镜头漫游快捷键、精准拖拽反馈和五层属性面板。
3. [**导入 FBX / GLB 模型**](import-fbx.md) —— 把外部 3D 模型导进资源库，直接拖进场景视口贴地落场。
4. [**编写与挂载 C# 脚本**](scripting.md) —— 一键建脚本、自动生成带中文提示的 `.sln` 工程、外部保存后切回窗口零重启热重载。
5. [**运行预览与实时调参**](run-preview.md) —— 切换窗口/全屏试玩，边玩边看动态生成的实体并把满意的参数保留回场景。
