# Flare 使用者文档

欢迎使用 **Flare 引擎**。你可以完全通过图形界面完成场景搭建、模型导入、C# 脚本挂载（零窗口重启热重载）、运行态实时调参与独立游戏导出。如果刚克隆了源码仓库，请先[从源码启动编辑器](build-from-source.md)。

## 五步上手第一个项目

1. [新建项目](create-project.md) · 使用清爽的「基础 3D 示例」创建第一个工程。
2. [编辑器界面与高效交互](editor-interface.md) · 熟悉 2×3 布局、文件夹分类资产栏、卡片属性栏与算式调参。
3. [导入 FBX / GLB 模型](import-fbx.md) · 把外部模型带入项目并拖入场景视口落场。
4. [编写与挂载 C# 脚本](scripting.md) · 搜索框一键新建脚本、外部改码切回零重启热重载、拖拽实体引用与 `[F_Range]` 滑条。
5. [运行预览与实时调参](run-preview.md) · 在摄像机视口切换窗口/全屏预览，边跑游戏边实时调参。

## 材质、布光与画质

- [用渲染工作室调光](rendering-studio.md) · 在带六种 PBR 材质的工作室里调节矩形补光与清漆/金属表面高光。
- [给室内展厅布光](indoor-lighting.md) · 摆放投影点光与聚光灯，观察柔和阴影、漫反射反弹、倒影与体积雾。
- [给玩家提供画质设置](player-quality.md) · 在项目设置配置多档画质，在导出的游戏中实时切换并保存。

## 玩法系统、动画与成片录制

- [预制体、拖放落场与玩法系统](gameplay-systems.md) · 零命令行完成预制体拖拽制作与同步、触发器、3D 空间音频、GPU 粒子、导航烘焙与 DXR 1.1 硬件光追开关。
