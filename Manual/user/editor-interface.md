# 编辑器界面与高效交互

本页带你一眼看懂 Flare 的 **2×3 工作区布局**、视口镜头操作、精准拖拽规则以及五层属性面板的高效用法。熟用本页的快捷键与拖拽技巧后，搭场景和调参数会顺手很多。

## 1. 一眼看懂 2×3 默认工作区

打开项目后，编辑器采用经典高效的 **2×3 布局**：左侧上下双视口（创作视野 + 玩家画面/日志），右侧三列通高并排（场景层级 | 资源库 | 属性面板）。

```text
+---------------------------------------------------------------------------------------------------+
| 菜单栏: 文件  编辑  运行预览  项目  面板  帮助                                                      |
| 工具栏: [保存] [撤销] [重做] [＋ 创建 ▾] [导入] [编译脚本]     [▶] [Ⅱ] [▸│]     [布局: 2×3 ▾] [构建导出] |
+----------------------------------------+----------------+------------------+----------------------+
| [场景视口] [UI 设计]                    | 场景层级        | 资源              | 属性             [🔓] |
|  [抓手 Q][移动 W][旋转 E][缩放 R]       |  ▾ Main Camera | [＋][搜索][全部▾] | [✓] Cube  #4  [静态▾]|
|  [局部][轴心] [天空][网格][手柄][查看全部]|    Directional | ▸ Content        | 标签: Untagged 层: 0 |
|                                        |    Plane       |   ◆ crate.glb    | ▾ Transform [局部|世界]|
|           3D 场景编辑视口               |    Cube        |   ● Metal.mat    |   位置  X   Y   Z    |
|                                        |                |   C# SpinCube.cs |   旋转  X   Y   Z    |
|----------------------------------------+                |                  |   缩放  X   Y   Z    |
| [摄像机视口] [控制台]                   |                |                  | ▾ Mesh        [⌖][⋮] |
|  [窗口预览] [全屏预览]                  |                |                  | ▾ SpinCube    [✓][⋮] |
|           实时玩家视角预览              |                |                  |    [ ＋ 添加组件 ]    |
+----------------------------------------+----------------+------------------+----------------------+
| 状态栏: 就绪                                                                                       |
+---------------------------------------------------------------------------------------------------+
```

**自由拼装与保存你的专属布局**：
- 按住任意面板的**页签标题**拖动：拖到屏幕外变成**独立浮动窗口**；拖到其他面板中心可**合并为页签**，拖到上下左右四边可**分屏停靠**。
- 点击右上角 **布局 ▾** 下拉菜单，可在 **2 by 3 布局**、**标准底栏布局**、**宽屏创作布局** 之间切换，也能点击 **保存当前布局** 持久化你调好的分屏，随时可点 **恢复默认 2 by 3 布局** 一键复原。

## 2. 场景视口：漫游、对齐与 3D 控制柄

### 镜头导航与变换快捷键

| 操作目的 | 鼠标 / 快捷键 | 实用说明 |
| :--- | :--- | :--- |
| **第一人称漫游** | 按住 **右键 + `WASD`**，`Q / E` 升降 | 按住 `Shift` 加速；按住右键同时滚轮可实时调节漫游移速。 |
| **环绕观察** | `Alt + 左键` 拖动 | 绕当前焦点自由旋转查看模型各面。 |
| **平滑缩放** | `Alt + 右键` 拖动，或直接滚动 **滚轮** | 滚轮配合 `Shift` 加速、`Ctrl` 慢速微调。 |
| **平移画布** | 按住 **中键** 拖动（或按 `Q` 切到抓手工具后左键拖动） | 平行上下左右挪动镜头。 |
| **聚焦与跟随** | `F` 聚焦选中物体；`Shift + F` 锁定跟随 | 未选中任何物体时按 `F`（或点视口右上角 **查看全部**）会框选整个场景。 |
| **对齐当前视角** | **`Ctrl + Shift + F`**（或 **编辑 → 对齐当前视角**） | 把场景镜头飞到理想机位后，选中 `Main Camera` 或聚光灯按一下即可瞬间同步位置与朝向（支持 `Ctrl+Z` 撤销）。 |
| **变换工具切换** | `Q` 抓手 / `W` 移动 / `E` 旋转 / `R` 缩放 | 缩放模式下拖动中心白盒可**三轴等比缩放**。 |
| **步进吸附** | 拖动 `W / E / R` 手柄时按住 **`Ctrl`** | 移动按 `0.25m`、旋转按 `15°`、缩放按 `10%` 整齐吸附。 |
| **坐标轴与枢轴** | `X` 切换 **世界 / 局部** 坐标；`Z` 切换 **轴心 / 中心** | 视口顶部浮条也可直接点选开关 **天空 / 网格 / 手柄**。 |
| **视口多选** | `Ctrl + 左键` 或 `Shift + 左键` 点击物体 | 可同时选中多个物体一起拖动、旋转、缩放。 |

### 直接在 3D 视口里拖光源与碰撞体控制柄

选中以下组件所在实体时，3D 视口中会自动显示对应的线框与可拖动圆点控制柄，**直接用鼠标拖就能所见即所得地调参**（支持 `Shift` 加速、`Alt` 微调，并自动合并为单条 `Ctrl+Z` 撤销）：

- **点光源**：拖动球面控制柄调整作用范围（`Range`）。
- **聚光灯**：拖动锥缘控制柄调整照射范围与外锥半角。
- **盒体/球体碰撞体、刚体、胶囊角色控制器**：直接拖动绿色控制柄调节半尺寸、半径或高度。
- 在属性面板点击组件标题右侧的 **`⌖`** 按钮，可一键激活该组件的 3D 控制柄并把视口聚焦到它身上。

## 3. 场景层级（Hierarchy）与精准拖拽

**场景层级** 展示当前场景里的全部实体和父子关系，支持以下高效操作：

- **单选 / 多选 / 聚焦**：点击单选，双击直接把视口聚焦到该物体；`Ctrl + 点击` 逐个增减多选，`Shift + 点击` 连续范围多选，批量移动/删除/克隆一气呵成。
- **建立或解除父子关系**：把一个实体拖到另一个实体行上松手，即可设为子物体并**自动保持世界坐标不变**；拖到列表底部空白处松手，即可移回根层级。
- **原位重命名**：选中实体后，**慢击一次文字标签**、按 **`F2`** 或右键选 **重命名**，即可原位改名（打开时自动全选高亮，支持鼠标点击定位光标、`Enter` 确认、`Esc` 取消）。
- **深度克隆（`Ctrl + D`）**：选中单个或多个实体按 `Ctrl + D`，会完整复制整棵子树，包括**所有组件参数、挂载的 C# 脚本及其暴露字段绑定、以及预制体关联与覆盖记录**（内部实体引用会自动重映射到克隆出的新节点，不会串回原物体）。

### 精准拖拽反馈：防误挂、拖出即建预制体

Flare 对跨面板拖拽做了明确的高亮与光标预检，松手前一眼就能确认落点是否正确：

| 拖拽起点 → 目标位置 | 悬停反馈 | 松手后的结果 |
| :--- | :--- | :--- |
| **C# 脚本 / 材质** → 场景层级**某一行实体** | **只高亮光标指中的那一行实体**，显示绿框与手型光标 | 直接把该脚本挂载到该实体，或将材质赋给该实体的网格。 |
| **C# 脚本 / 材质** → 场景层级**空白处** | 不高亮任何行，鼠标变为**禁止光标 (`⊘`)** | 拒绝放下，彻底防止误挂到不相干的物体上。 |
| **模型 / 预制体** → 场景层级**某一行或空白处** | 绿色边框高亮 | 直接在场景中创建该模型或实例化该预制体（拖到某行上会直接挂成其子物体）。 |
| **场景实体** → **资源**面板（或其文件夹） | 高亮资源面板区域 | **一键在当前目录生成 `<实体名>.prefab.json` 预制体**，并自动将场景中的该实体转为预制体实例。 |
| **材质 `.material.json`** → 3D **场景视口**网格 | 悬停不松手即可**实时预览 PBR 材质效果** | 松手后正式赋予材质；移开或取消则恢复原样。 |
| **任意资源** → 属性面板的**资产槽位** | 类型匹配显示**绿框 + 手型光标**；不匹配显示**红框 + 禁止光标** | 自动预检，避免把贴图误拖进网格槽。 |

## 4. 资源（Assets）面板：分类整理与保护后缀重命名

- **新建与导入**：点击顶栏 **`＋`** 或右键空白处，可一键 **新建文件夹**、**新建材质**、**创建 C# 脚本**、**创建昼夜配置**、**烘焙场景导航网格**，或点 **导入** 引入外部模型/贴图/音频。
- **列表 / 大图标双视图与筛选**：面板足够宽时可点顶栏切换 **列表 / 图标** 视图（也可在面板内按住 `Ctrl + 滚轮` 快速切换）；顶栏支持按名称搜索、按类型下拉筛选，以及点击**面包屑路径栏**快速跳回上级文件夹。
- **拖拽归档**：直接把资源拖到某个文件夹行或面包屑路径上即可移动归档。
- **安全原位重命名（保护后缀）**：无论在列表还是图标视图下，**慢击已选资源的文字**、按 **`F2`** 或右键选 **重命名** 都能原位改名：
  - 编辑器默认**只全选扩展名前的主文件名**，直接打字就不会误删 `.cs` / `.png` / `.fbx` 后缀。
  - 重命名已被场景引用的 UUID 资产时，资产 ID 会保持不变，不会断引用；重命名 C# 脚本时还会同步更新脚本内的类名。

## 5. 右侧属性面板（Inspector）全解析

属性面板按五层清晰排布，把身份、变换、组件、诊断和高级工具各归其位：

### 第一层：实体头与共享资产提示
- **顶部身份栏**：左侧复选框控制实体启停（`Active`），中间显示名称与只读 `#稳定ID`，右侧提供：
  - **静态（`StaticFlags`）**：可设为 **自动推导**、**纯动态**、**全部静态**，或单独勾选 **静态合批与阴影 / 导航网格烘焙 / 全局光照探针 / 遮挡剔除体**。
  - **标签（`Tag`）**：如 `Untagged`、`Player`、`MainCamera`、`Enemy`、`Interactable`、`Trigger`、`Respawn`、`Finish`，供脚本 `CompareTag` / `F_Scene.FindWithTag` 使用。
  - **层级（`Layer 0..31`）**：控制碰撞与射线过滤（内置 `0: Default` 到 `9: Environment` 等常用语义层）。
- **预制体顶栏**：选中预制体实例时，实体头下方紧贴显示 **`◆ 预制体名`** 与 **[定位资产] / [还原全部覆盖] / [应用覆盖回预制体]**，也支持针对单个属性或单个组件做颗粒度还原与回写。
- **共享材质防误改横幅**：选中资源面板里的 `.material.json` 时，顶部会显示蓝色提示条 **`共享材质资产 · 当前场景引用数 (N)`**，并提供 **[实例化独立材质并赋给选中物体]** 按钮，一键克隆独立副本，改色不怕连累其他物体。

### 第二层：变换（Transform）与坐标切换
- **始终置顶**且不可误删，顶部可直接切换 **`局部 (Local) | 世界 (World)`** 坐标空间：
  - 切到 **世界 (World)** 模式修改位置/旋转/缩放时，编辑器自动通过父节点逆矩阵换算写回局部值；如果父节点存在旋转叠加非等比缩放导致的切变，面板会给出提示并保护旋转/缩放为只读，防止数值跑飞。
  - 内置连续欧拉角编辑，输入 `185°`、`360°` 或 `-270°` 不会发生莫名其妙的跳变翻转。

### 第三层：组件栈、菜单与依赖保护
- 每个 C++ 组件与 C# 脚本卡片顶部都统一带有：**启用复选框**、**`⌖` 视口控制柄聚焦**（空间类组件）以及右上角 **`⋮` 组件菜单**：
  - **重置为默认值** / **上移组件** / **下移组件**
  - **复制组件参数** / **粘贴组件参数**（切到另一个实体点底栏可 **粘贴为新组件**）
  - 脚本卡片还可直接点 **编辑 C# 脚本** 或 **移除组件**。
- **前置依赖与互斥保护**：添加 **动画角色** 时若缺少 **网格** 组件会自动补齐；试图删除正被其他组件依赖的组件，或给同一实体同时添加 **刚体** 与 **胶囊角色控制器** 时，会直接拦截并在状态栏说明原因。

### 第四层：智能调参、多选混合态与内联 [一键修复]
- **拖动调参**：鼠标移到字段标签或 `X / Y / Z` 彩色徽标上（光标变为左右箭头 `↔`），按住左键左右拖动即可丝滑调参；按住 `Shift` 加速 `10×`，按住 `Alt` 微调 `0.1×`。
- **内置计算器与相对运算**：任意数值输入框都支持直接输入公式并按 `Enter` 求值：
  - 支持 `+ - * / % ^`、括号、常量 `pi` / `tau` / `e`，以及 `sin`、`cos`、`sqrt`、`deg`、`rad` 等函数（例如输入 `1920/2` 或 `sqrt(2)`）。
  - 支持 **`+=` / `-=` / `*=` / `/=` 相对运算**（例如给多选的 5 个柱子在位置 Y 框里输入 `+=2.5`，全部一起抬高 `2.5m`）。
- **多选混合态（`—`）**：同时选中多个实体时，数值相同的字段直接显示共同值，不同的字段显示 **`—`**；只需改你关心的那个字段，其余混合字段不会被误覆盖。
- **系统剪贴板无缝互通**：所有文本/数值输入框均原生支持 **`Ctrl + C / Ctrl + X / Ctrl + V`** 与 Windows 系统剪贴板互通，以及 `Ctrl + A` 全选和中文输入法（IME）。
- **内联告警与 `[一键修复]`**：遇到常见配置坑时，组件卡片内会直接弹出黄色告警条和右侧修复按钮，点一下就能修好：

| 告警场景 | 内联修复按钮 |
| :--- | :--- |
| 网格资产引用缺失或失效 | **[换用立方体]** |
| 材质槽引用了已删除的材质 | **[清空失效槽]** |
| 球体/胶囊碰撞所在实体存在非等比或近零缩放 | **[归一等比缩放]** |
| 场景无主相机，或同时有多个主相机 | **[设为唯一主相机]** |
| 3D 音源最小衰减距离大于最大距离 | **[修正衰减范围]** |
| 动画角色所选片段名在当前模型里不存在 | **[选用首个片段]** |

- 底部默认折叠的 **运行与派生诊断 (只读)** 卡片收纳了世界包围盒尺寸、层级实际激活状态、网格顶点数/三角面数、当前物理状态等只读信息，排错时展开即看。

### 第五层：面板锁定 `🔒`、`Ping` 闪烁定位与 `⊙` 搜索选择器
- **锁定检视目标（`🔒 / 🔓`）**：点击属性面板页签右侧的小锁图标变成 **`🔒`**（显示「已锁定」徽标）后，再去场景层级点别的物体或去资源面板切目录，属性面板都不会切走——非常适合把深层目录里的材质、模型或实体批量拖进目标槽位。
- **一键定位（Ping）**：点击属性面板里已赋值的**实体槽**或**资产槽**，编辑器会在场景层级或资源面板里自动滚到对应项并蓝色闪烁高亮定位。
- **即时搜索选择器（`⊙`）**：点击实体槽或资产槽右侧的 **`⊙`** 按钮，会弹出带搜索框的选择器，输入关键词即可挑选同类型资产或场景实体，不用来回拖拽；点 **`×`** 可一键清空槽位。
