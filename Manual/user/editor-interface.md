# 编辑器界面与高效交互

Flare 默认采用直观的 **2×3 工作区布局**，把画面观察、资产组织与组件调参清晰分区：

1. **左侧上方 · 场景视口 / UI 设计**
   - 按住 **鼠标右键 + `WASD`**（`Q/E` 升降、`Shift` 加速、右键滚轮调节移速）自由漫游；按住 `Alt + 左键` 环绕、中键平移、滚轮缩放。
   - 选中物体后按 `W / E / R` 切换移动、旋转、缩放手柄，`X` 切换世界/局部坐标，`F` 聚焦选中物体；拖动缩放手柄中心白盒可**三轴等比缩放**，按住 `Ctrl` 拖动手柄可触发**步进吸附**（平移 `0.25m`、旋转 `15°`、缩放 `10%`）；选中点光源、聚光灯、碰撞体或角色控制器时，还可在 3D 视口直接拖动线框控制柄实时调节照射半径、外锥角或碰撞尺寸并自动记入单条撤销。
   - **视角一键对齐（`Ctrl+Shift+F`）**：先把场景观察镜头飞到满意的构图角度，选中 `Main Camera` 或灯光后按 `Ctrl+Shift+F`（或菜单 **编辑 → 对齐当前视角**），即可将它的位置和朝向一步对齐到当前视野，支持 `Ctrl+Z` 撤销。
2. **左侧下方 · 摄像机视口 / 控制台**
   - **摄像机视口** 实时预览玩家视角，按 `F5` 或 `Ctrl+P` 即可启动/停止预览（若脚本有未编译改动会自动先编译再启动，编译报错会拦截启动并定位到控制台）；顶栏可随时切换 **窗口预览** 与 **全屏预览**。
   - **控制台** 顶栏提供 **清空**、**折叠重复**、**运行清空** 以及右侧 **信息 / 警告 / 错误** 计数筛选；双击带 `Scripts/文件名.cs(行,列)` 的日志或报错行可直接跳到外部代码编辑器对应位置。
3. **中部上方 · 场景层级（Hierarchy）**
   - 列出当前场景的所有实体与父子层级，支持 **`Ctrl+点击` 增减多选** 与 **`Shift+点击` 连续范围多选**（批量移动/旋转/缩放、批量删除与 `Ctrl+D` 批量克隆），支持慢击已选中物体的文字标签、按 `F2` 或右键 **重命名** 原位改名（带全选高亮与点击定位光标）。拖拽实体建立父子关系时**自动保持世界坐标不变**，拖到底部空白区即可解除父子关系回到根层级；将实体直接拖入下方 **资源** 面板即可生成 `.prefab.json` 预制体。
4. **中部下方 · 资源（Assets）**
   - 点击左上角 **`+`** 按钮或右键空白处可 **新建文件夹 / 材质 / C# 脚本**，在列表与大图标网格视图下均支持慢击文字/`F2`/右键 **重命名**（默认仅全选扩展名前的主文件名以保护后缀，含已被场景引用的 UUID 资产与 C# 脚本类名同步重命名）、路径面包屑跳转与拖拽归档。
   - **拖拽预检与实时材质预演**：把资源拖向属性栏槽位时未松手即校验类型匹配（匹配显示绿框与手型光标，不匹配显示红框与禁止光标）；将 `.material.json` 拖过 3D 场景视口网格表面时未松手即可实时预览 PBR 着色效果。
5. **右侧通栏 · 属性（Inspector · 五层 GameObject 契约面板）**
   - **第一层 · 实体头与共享资产隔离**：顶部仅保留纯粹的世界级身份与路由契约——启用复选框（`Active`）、名称与只读 `#StableId` 徽标、**动静契约（`StaticFlags`）** 位掩码（自动推断 / 纯动态 / 静态合批 / 导航网格 / 全局光照 / 遮挡剔除），以及 **标签（`Tag`）** 与 **碰撞/渲染层（`Layer 0..31`）**；场景全局环境（`SceneEnvironment` / `TOD`）仅在未选中实体或选中 `.tod` 资产时显示，绝不混入单个实体的 GO 面板。预制体实例紧贴实体头展示 **`◆ 预制体名 [定位] [还原] [应用]`** 顶栏，支持属性右键与组件菜单级颗粒度还原或回写原型；选中共享 `.material.json` 时顶部显示引用计数提示横幅并提供 **[克隆并挂载独立材质]** 一键解耦。
   - **第二层 · 空间锚点（Transform）**：锁定在首位且不可移除/排序，内置 **`局部 (Local) | 世界 (World)`** 语义坐标切换（自动处理父节点矩阵求逆，父节点含旋转非等比切变时自动提示并保护旋转/缩放），并维护连续欧拉角缓存，输入 `185°`、`360°` 或 `-270°` 不会发生四元数跳变。
   - **第三层 · 组件生命周期栈与跨面板桥接**：所有 C++ 组件与 C# 脚本统一具备启用复选框、**`⌖` 空间手柄一键激活聚焦**按钮以及 **`⋮` 组件菜单**（语义化**重置默认值**、**上移 / 下移顺序**、**复制组件**、**粘贴组件数值**、底栏**粘贴为新组件**）；挂载骨骼角色（`SkeletalActor`）自动补齐前置 `Mesh` 依赖，试图移除仍被依赖的基础组件或挂载互斥物理组件时前置拦截并在状态栏/控制台给出原因。
   - **第四层 · 参数语义化、条件显隐与内联一键修复**：数值框标注物理单位（`m`、`°`、`kg`、`s`、`m/s`、`lx`、`lm`、`cd/m²`）与线性色彩空间徽标（`Linear`），并根据状态动态隐藏无效死参数（如盒体/球体碰撞切换、静态质量隐藏阻尼、2D 音源隐藏衰减距离、渲染设置按子标题折叠与总开关门控）；缺失网格/材质、球体碰撞非等比缩放、无主相机或多主相机、3D 音源最小距离超界等异常直接在组件内联显示黄色告警条与 **[一键修复]** 按钮；运行态只读派生数据统一收拢至底部默认折叠的 **运行态与派生诊断** 卡片。
   - **第五层 · 面板锁定、引用定位选择器与运行期保留**：点击属性页签右侧 **`🔒 / 🔓`** 即可锁定当前检视对象，方便在场景层级或资源面板跨目录拖拽绑定而不切走面板；实体槽与资产槽支持**点击槽位闪烁定位（Ping）**、**`⊙` 即时搜索选择器**与 `×` 一键清空；运行预览（Play Mode）顶栏提供 **[保留此实体修改]** 开关，勾选后退出预览可将运行期调好的组件与脚本参数作为单条 `Ctrl+Z` 撤销事务写回编辑场景。
   - **快捷拖拽与数学表达式**：悬停在字段名或坐标轴徽标左右拖动即可自适应量级调参（`Shift` 加速、`Alt`/`Ctrl` 微调）；数值框内置 `1920/2`、`sin(0.5)`、`sqrt(2)`、`deg/rad`、`pi` 求值及 `+=` / `-=` / `*=` / `/=` 相对运算；点击底部 **+ 添加组件** 打开模糊搜索框添加组件或新建 C# 脚本。

**自由定制与保存布局**：按住任意面板页签即可拖出为独立浮动窗口，或拖到其他区域中心合并、四边分屏。右上角 **布局** 下拉菜单不仅可切换预设，还支持 **保存当前布局**（持久化自定义分屏配置）与一键恢复默认布局。
