# 编辑器界面与高效交互

Flare 默认采用直观的 **2×3 工作区布局**，把画面观察、资产组织与组件调参清晰分区：

1. **左侧上方 · 场景视口 / UI 设计**
   - 按住 **鼠标右键 + `WASD`**（`Q/E` 升降、`Shift` 加速、右键滚轮调节移速）自由漫游；按住 `Alt + 左键` 环绕、中键平移、滚轮缩放。
   - 选中物体后按 `W / E / R` 切换移动、旋转、缩放手柄，`X` 切换世界/局部坐标，`F` 聚焦选中物体；拖动缩放手柄中心白盒可**三轴等比缩放**，按住 `Ctrl` 拖动手柄可触发**步进吸附**（平移 `0.25m`、旋转 `15°`、缩放 `10%`）。
   - **视角一键对齐（`Ctrl+Shift+F`）**：先把场景观察镜头飞到满意的构图角度，选中 `Main Camera` 或灯光后按 `Ctrl+Shift+F`（或菜单 **编辑 → 对齐当前视角**），即可将它的位置和朝向一步对齐到当前视野，支持 `Ctrl+Z` 撤销。
2. **左侧下方 · 摄像机视口 / 控制台**
   - **摄像机视口** 实时预览玩家视角，按 `F5` 或 `Ctrl+P` 即可启动/停止预览（若脚本有未编译改动会自动先编译再启动，编译报错会拦截启动并定位到控制台）；顶栏可随时切换 **窗口预览** 与 **全屏预览**。
   - **控制台** 顶栏提供 **清空**、**折叠重复**、**运行清空** 以及右侧 **信息 / 警告 / 错误** 计数筛选；双击带 `Scripts/文件名.cs(行,列)` 的日志或报错行可直接跳到外部代码编辑器对应位置。
3. **中部上方 · 场景层级（Hierarchy）**
   - 列出当前场景的所有实体与父子层级。拖拽实体建立父子关系时**自动保持世界坐标不变**，拖到底部空白区即可解除父子关系回到根层级；将实体直接拖入下方 **资源** 面板即可生成 `.prefab.json` 预制体。
4. **中部下方 · 资源（Assets）**
   - 点击左上角 **`+`** 按钮或右键空白处可 **新建文件夹 / 材质 / C# 脚本**，支持 `F2` 重命名（含已被场景引用的 UUID 资产与 C# 脚本类名同步重命名）、路径面包屑跳转、列表/图标网格视图切换与拖拽归档。
   - 每类资源均带有醒目的彩色类型徽标（场景、材质、模型、贴图、预制体、音频、C# 脚本等），一眼区分用途；可直接将模型/预制体拖入场景视口落场，或将材质拖到模型上换肤。
5. **右侧通栏 · 属性（Inspector）**
   - 选中实体后顶部可快速勾选**启用状态**，并以卡片样式展示各组件；点击组件右上角 **`⋮`** 可执行 **重置变换**、**编辑 C# 脚本** 或 **移除组件**。选中 `.material.json` 材质资产时，亦可直接在属性栏内联调节基础色（HSV/RGB 拾色器）、金属度/粗糙度滑条与贴图槽位。
   - **快捷数值输入**：将鼠标悬停在字段名或坐标轴标签（显示 `↔` 光标）左右拖动即可丝滑调参；数值框原生支持四则运算表达式（如输入 `360/8`、`10+2.5*2`、`2*pi` 回车自动算出结果）。
   - 点击底部的 **+ 添加组件** 打开即时模糊搜索框，快速添加引擎组件或一键创建并挂载新 C# 脚本。

**自由定制布局**：按住任意面板页签即可拖出为独立浮动窗口，或拖到其他区域中心合并、四边分屏。如果误关了某个面板，从顶部 **面板** 菜单重新勾选，或在右上角 **布局** 下拉菜单中一键恢复默认布局。
