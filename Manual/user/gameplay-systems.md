# 预制体、拖放落场与玩法系统（零命令行指南）

本页介绍如何完全通过编辑器界面与鼠标快捷键完成预制体制作、资产拖放落场、触发器、3D 音效、GPU 粒子、导航网格烘焙以及高阶渲染开关配置，全程无需打开终端。

## 从资产面板拖放落场

1. 在底部 **资源** 面板选中已导入的模型（`.fbx` / `.glb`）或预制体（`.prefab.json`）。
2. 按住鼠标左键拖入中间的 **场景视口**，光标落点会沿当前视口射线自动贴合地面或已有物体表面（按住 `Ctrl` 吸附到网格）。
3. 松开鼠标即可在目标位置创建实体；不满意可随时按 `Ctrl+Z` 一步撤销。

## 制作与同步预制体

1. 在 **层级** 面板搭建好包含父子物体、组件或 C# 脚本的子树。
2. 右键根节点选择 **创建预制体**，输入名称后会在项目资源目录生成 `.prefab.json` 资产，且场景中该节点自动显示预制体链接标记。
3. 从资源面板多次拖出同一预制体，可在 **属性** 面板单独修改某一个实例的位置、颜色或组件参数（覆盖值会保留，不会被母版冲掉）。
4. 选中已修改的实例，在属性面板点击 **应用覆盖回预制体** 可把改动同步到全部同源实例，点击 **还原全部覆盖** 则恢复为母版默认值。

## 触发器、手柄与动作输入

1. 选中实体后在属性面板添加 **碰撞体与触发器** 组件，勾选 **是否为触发器** 并选择盒形或球形尺寸。
2. 在 C# 行为脚本中监听 `OnTriggerEnter` / `OnTriggerExit`，并通过 `Actions.IsActionPressed("Jump")` 或 `Actions.GetAxis2D("Move")`（或 `Session.Actions`）响应键鼠与 XInput 手柄，无需硬编码按键编号。

## 3D 音频与 GPU 粒子

1. **添加监听器与音源**：主相机实体添加 **音频监听器**，场景发声实体添加 **音源** 并指定已导入的 WAV/OGG 音频资产，调节 **空间混合（0 2D / 1 3D）**（`0` 为背景音乐，`1` 为 3D 空间衰减声源）与最小/最大衰减距离。
2. **添加粒子特效**：在层级面板右键或通过属性面板添加 **粒子发射器**，选择发射形状（点/球/锥形）、发射速率、起止尺寸与颜色渐变，勾选 **叠加混合** 可制作火花或能量光效，点击 **运行预览** 即可查看带软粒子深度过渡的实时效果。

## 导航网格烘焙与角色寻路

1. 摆放好地面与静态障碍物后，打开 **资源与参考工具** 面板，将类别设为 **几何烘焙**、操作设为 **当前场景导航网格**。
2. 设置 **体素边长（米）** 后点击 **运行**（后台线程异步烘焙，不阻塞界面操作），完成后自动生成 `scene.senav` 并登记到项目资产清单。
3. 为移动角色实体添加 **胶囊角色控制器** 与 **导航代理** 组件，指定刚烘焙的 `.senav` 资产；在脚本中调用 `Session.Navigation.SetDestination(Entity, target)` 即可自动沿拐点避障移动。

## 昼夜联动与高阶渲染开关

在 **场景渲染设置** 组件的属性面板中可直接勾选：

- **昼夜光照联动**：接入场景的昼夜配置后，拖动昼夜时间轴即可在视口实时预览日出、正午、黄昏到夜晚的太阳阴影与大气散射变化。
- **动态间接光（屏幕空间）**：在室内场景开启实时时域降噪间接光。
- **优先使用硬件网格着色器**、**瞬态显存物理别名**、**静态级联阴影缓存** 与 **静态网格空间合批**：按显卡与关卡特征启用对应加速路径；硬件不支持 SM 6.5 网格着色器时会自动回退至 Compute 间接路径，无需手动切换。
