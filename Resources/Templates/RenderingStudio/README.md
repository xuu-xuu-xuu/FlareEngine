# 渲染工作室

在 Flare 启动页选择“新建项目 → 渲染工作室”，选择项目位置后创建。创建的是独立可编辑工程；也可以在启动页打开该目录的 `project.json`。

场景前排从左到右为清漆、绒布、拉丝金属，后排为次表面漫反射、裁切、半透明混合。所有球体、地面和参照块都使用引擎内置几何，没有外部模型。选择对象修改变换与材质槽；在资源面板选择 `Content/Materials` 中对应材质，可调整颜色、粗糙度和各层参数。渲染设置对象集中保存 CSM、AO、接触阴影与后处理开关。

裁切球使用随模板分发的一张原始小型 alpha 纹理，可修改 cutoff 观察孔洞与投影。半透明球后方有参照块，透明度由基础色的 alpha 决定；这是线性透明混合，不提供折射。次表面材质是预积分漫反射，不表示厚度透射。

模板默认启用 Full PBR、三级方向光阴影、AO、接触阴影、镜面多散射、ACES 和轻微 Bloom/FXAA。TAA 与 4× 超采样保留在设置中按需开启。工作室使用随模板分发的真实柔和 IBL 环境，全局 SH 从该环境辐照数据投影；局部 SH 保持关闭，不会用重复数据冒充局部 GI。

`Scripts` 沿用基础示例的同一份脚本工程，默认绑定处于禁用状态，不旋转任何对象。正式编辑器包可复用匹配的预编译脚本；修改脚本后需要 .NET 10 SDK。使用编辑器的构建与导出面板生成游戏。

材质查表资源来自引擎正式资源链，不在此项目中重复烘焙或复制。环境的源 HDR 与重建配方保存在 `Sources`。缺少正式查表或环境资源时引擎会给出降级诊断；模板文件本身不作为渲染功能验收证明。
