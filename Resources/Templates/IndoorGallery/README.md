# 室内展厅

打开 Flare 启动器，选择 **新建项目 → 室内展厅**，给展厅取名后创建。以后可以从最近项目继续或打开该项目的 `project.json`。主相机面对陶瓷展桌和背墙装饰画；点播放进入这个固定镜头，停止后回到编辑视口。

| 在层级中选择 | 在属性中修改 | 观察位置 |
| --- | --- | --- |
| 琥珀点灯 · 桌面投影 | 先记下原位置，移动灯，再开关 **投射局部阴影** | 看黄铜桌脚在地坪上的投影是否跟着灯位移动 |
| 轨道聚光 · 展台 | 旋转灯或改变 **外锥半角（度）** 与 **内锥半角（度）** | 观察展台光斑的方向、范围与边缘过渡 |
| 室内光照设置 | 切换 **动态间接光（屏幕空间）** | 比较铁红墙附近被反射光染色的暗部 |
| 室内光照设置 | 切换 **动态反射（屏幕空间）**，或移动可见展品 | 在抛光地坪中观察展品反射的变化 |
| 室内光照设置 | 切换 **体积雾**，调整 **每米雾消光系数** | 在侧窗和聚光照到的空气中观察散射及远处对比度 |

对照时保持主相机与曝光固定，每次只改一项。动态间接光与反射使用当前屏幕可见表面，镜面追踪未命中时保留环境反射。编辑新的点光源或聚光灯时，可以右键场景层级创建，再在属性面板调色、设范围和阴影。保存场景后，运行和导出都使用该项目里的灯光设置。
